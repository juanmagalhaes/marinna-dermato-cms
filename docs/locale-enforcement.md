# Locale / i18n (histórico)

**Estado atual:** o site é **apenas pt-BR**. Não há campos de locale no CMS nem enforcement por hooks.

O idioma e `openGraph.locale` são **fixos no Next.js** (ver `docs/seo-plano-referencia.md`).

Este ficheiro mantém-se só como referência de que práticas antigas (hooks `pt_BR`, campo `locale` no SEO) **foram removidas**.
